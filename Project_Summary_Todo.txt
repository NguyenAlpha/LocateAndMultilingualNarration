3) LUONG CHINH DANG CHAY TREN MOBILE (THEO CODE)
---------------------------------------------------------------------
Luong A - Startup:
LoadingPage -> check DeviceId -> check QR access -> check local preference
=> route ScanPage / MainPage / LanguagePage

Luong B - QR:
ScanPage -> ScanViewModel -> QrService.VerifyAsync
=> SaveAccess(expiry) -> navigate LanguagePage

Luong C - Preference:
LanguageViewModel load language + voice
=> DevicePreferenceApiService.UpsertAsync
=> navigate MapPage

Luong D - Map/Narration:
MapViewModel load stalls (cache-first)
MapPage render pin + geofence
Tap pin => StallPopup => play audio

Luong E - Geofence queue:
GpsPollingService tick -> MapViewModel.CheckGeofencesAsync
-> enqueue stall moi trong vung
-> neu khong dang phat thi play ngay
-> playback complete thi play item tiep

Luong F - Background sync:
SyncBackgroundService:
- Every 3 min: SyncService.SyncAsync (stalls + audio cache)
- Every 1 min: LocationLogService.FlushAsync (batch location)
- Khi reconnect: trigger sync + flush ngay
